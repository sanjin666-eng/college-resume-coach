# 阶段三：可编辑 A4 HTML 简历

## 输入与交付

仅以用户最终确认的简历文字版 `.md` 为内容来源。第三阶段的正式产出必须是 `{姓名}-简历.html`；姓名未知时使用 `简历.html`。交付单文件、无外部依赖的 HTML，本地打开即可编辑、打印或导出 PDF。

把 Markdown 中的简历正文视为锁定文本：不得删减、缩写、合并、润色、改写、调换要点内部顺序或新增内容。先按原文生成完整 HTML，再让用户查看排版并主动提出修改建议。即使单页空间不足，也不得自行改文案；应通过排版参数处理，仍无法容纳时保留完整内容并向用户说明可选方案。

HTML 应内嵌全部 CSS 和 SVG 图标；禁止 CDN、远程字体、网络图片和脚本依赖。除照片区域外，页面全部文字使用 `contenteditable="true"`；为页面主体设置清晰的可编辑提示，但打印时隐藏提示和编辑焦点样式。

交付版本必须已经完成 A4 版面适配，不能把默认字号和间距直接套用后未经渲染检查就交付。HTML 同时提供屏幕态排版工具栏，让用户能在不修改代码的情况下继续微调字体与段落样式。

## 页面规格与视觉

- A4 纵向：`210mm × 297mm`；白底，无底纹、渐变、阴影或大面积装饰。
- 单栏纵向时间线，禁止左右双栏。
- 主色 `#4E7282`；辅助深色 `#27424D`；正文 `#111111`，不得引入额外高饱和强调色。
- 左右边距 11–12mm，上边距 9–10mm，下边距 8–10mm；主内容宽 186–188mm。
- 顶部个人信息区高 36–40mm。
- 从首个经历模块开始，在页面左侧 15–17mm 位置绘制 `#27424D` 纵向时间线，线宽 0.25–0.35mm；模块标题色块覆盖在线上。
- 模块正文左边缘位于 21–22mm；所有模块左边缘、右侧日期和分隔线严格对齐。

使用 CSS 的 `@page { size: A4 portrait; margin: 0; }` 和打印媒体规则固定输出。屏幕模式可在页面外显示浅灰工作区，但 A4 页面本身保持纯白且打印时只输出页面。

## 字体

整份简历统一使用：`"Microsoft YaHei", "Noto Sans CJK SC", sans-serif`，不得混用宋体、楷体、衬线或艺术字体。

- 姓名：24pt，加粗。
- 一级模块标题：12pt，加粗。
- 学校/公司/岗位/日期：11–11.1pt，加粗。
- 顶部联系信息：10.5pt。
- 正文：9pt；溢出调整时最低 8.5pt。

## 顶部个人信息区

三段式横向布局：

- 左侧姓名：左距页面 16–17mm，上距 13–15mm，单行、24pt、主色粗体。
- 中部信息：依次为求职意向、手机、邮箱；10.5pt，行距 1.35–1.45，标签与内容同行左对齐，无图标和表格边框。
- 右侧照片：宽 24–26mm、高 32–34mm的竖版矩形，右上角对齐；无圆角、圆形裁切、阴影。用户未提供照片时显示 `点击上传照片` 占位提示，不生成虚构人像。
- 照片区域必须可以点击，也必须支持键盘聚焦和 Enter/Space 触发。使用隐藏的 `<input type="file" accept="image/*">` 选择本地图片。
- 使用浏览器 `FileReader` 在本地读取图片并写入 `<img>` 的 data URI，仅用于当前页面预览和打印，不发起上传或网络请求。
- 照片上传后保持 24–26mm × 32–34mm 证件照区域，使用 `object-fit: cover` 居中裁切，不拉伸、不改变顶部信息区尺寸。再次点击照片区域可以更换图片。
- 未选择照片时打印占位框；已选择照片时打印实际照片，并隐藏“点击上传照片”等提示。

若用户在生成简历前已提供本地照片，为维持“单文件”要求，将照片转换成内嵌 data URI；不得链接本地绝对路径。用户在生成后通过页面选择的照片只在浏览器当前页面中预览，除非另有明确的本地保存功能，不得声称照片已永久写回 HTML 文件。

## 一级模块标题

教育、实习、项目、校园、技能模块统一：

- 高 6.3–6.8mm 的蓝灰色横向色块，起点 11–12mm，主体宽 34–39mm，并按标题长度小幅自适应。
- 右端使用 CSS `clip-path` 或伪元素实现斜切梯形尖角。
- 左侧内嵌白色单色 SVG：教育为学士帽，实习为公文包/证件卡，项目为项目符号，校园为爱心，技能为扳手。
- 图标右侧为 12pt 白色粗体标题。
- 色块右侧接主色细横线至正文右边缘，粗 0.3–0.5pt，在所有模块保持相同垂直位置。

只渲染有内容的模块。不得通过 emoji 或外部图标库实现图标。

## 内容模块

### 同模块经历排序

- 在同一个内容模块内，按照每段经历的开始时间从早到晚排列。
- 跨年份经历以开始年月为排序键，不以结束时间或持续时间排序。
- 示例：`2024.12–2025.1` 必须排在 `2025.2–2025.4` 之前。
- “至今”只影响结束时间，不改变开始时间排序规则；开始时间缺失的经历放在该模块最后并保留 `【待补充】`。
- 排序只改变完整经历块的位置，不改变块内标题、角色、日期或要点文字。

### 教育经历

使用 CSS Grid 构造无边框三列视觉行：学校左对齐、专业居中、时间右对齐。头部 11pt、主色、粗体；时间统一为 `YYYY.M–YYYY.M`。下方用圆点列出核心课程、GPA/排名和荣誉，正文 9pt、紧凑排版。

### 实习 / 项目 / 校园经历

- 经历头部使用 CSS Grid，无边框：左侧组织/项目名称，中间角色/岗位，右侧时间；角色起始视觉位置约 74–78mm，日期右对齐并距页面右边缘 15–17mm。
- 描述采用 `1. 2. 3.` 编号，每条以黑色粗体能力标签开头，后接正文；9pt，行距 1.25–1.35，使用悬挂缩进。
- 同模块多段经历不重复一级标题；项目头部之间留 1.5–2.5mm，不加额外横线。

### 技能工具

置于内容顺序的最后，每行采用“黑色粗体分类标签 + 技能内容”；不使用等级条、百分比、星级或雷达图。

## 单页溢出策略

目标为单页 A4，并同时避免“内容挤在页面上半部、下半部大面积空白”。先以实际打印尺寸渲染，再根据内容高度调整。正文末端通常应落在页面下边距上方约 `4–12mm` 的范围内；允许因完整经历块避分页而略有差异，但不能为了铺满页面制造夸张空隙。

内容偏短时，按以下顺序逐步舒展，每次调整后重新渲染检查：

1. 增加模块间距、经历块间距及条目段后距；
2. 将正文行距在 `1.25–1.40` 范围内适度增加；
3. 将正文在 `9–10pt` 范围内适度增大，并同步检查标题层级和换行；
4. 必要时微调顶部信息区高度，但不得破坏照片比例和对齐。

内容偏长时，严格按顺序处理：

1. 只调整段后间距、模块间距和布局参数，不改动已确认正文。
2. 将正文行距逐步降至最低 1.2。
3. 将正文逐步降至最低 8.5pt。
4. 仍放不下一页时，先生成完整可读版本并向用户说明，由用户选择删除内容、接受多页或提出其他修改；未经用户明确指示不得删减或合并文字。

不得删除任何已确认文字、让照片失衡，或造成压线、重叠、截断。不得使用固定高度配合 `overflow: hidden` 掩盖超页；可在屏幕态提示溢出，但打印内容必须完整。不要擅自生成难以阅读的版本。

## 禁止项

禁止双栏和侧边个人简介；禁止大面积彩色背景、圆形头像、装饰曲线、渐变、阴影、卡片；禁止额外强调色；禁止更改标题斜切色块语言；禁止页眉、页脚、页码、水印、Logo、可见表格边框；禁止正文居中；禁止擅自调整模块顺序。

## 可编辑与打印实现

- 给可编辑区域提供可见但克制的屏幕态轮廓或悬停提示；`@media print` 中彻底隐藏。
- 提供固定或悬浮的屏幕态排版工具栏，并在 `@media print` 中隐藏。工具栏至少包含：正文大小、行间距、段间距、加粗、斜体、恢复默认值。
- 正文大小、行间距和段间距优先通过 CSS 自定义属性统一控制，例如 `--body-font-size`、`--body-line-height`、`--paragraph-gap`；控件需显示当前值，并设置可读性安全范围：正文 `8.5–10pt`、行距 `1.2–1.45`、段间距 `0–2.5mm`。
- “加粗”和“斜体”作用于用户当前选中的文字，生成可打印的语义化 `<strong>` / `<em>` 或等效内联样式；没有文字选区时不应破坏全文结构。工具栏操作不得改写文字内容。
- 用户调整后的样式必须立即反映到 A4 页面和打印输出。每次调整后运行溢出检测，并以明确但克制的屏幕提示告知“页面适配”或“内容超出 A4”；提示不得进入打印结果。
- 工具栏及脚本必须完全本地运行，不记录、不上传简历内容。若提供“保存当前 HTML”，必须把当前内容和样式写入下载的新文件，并明确浏览器中的临时修改不会自动覆盖原文件。
- 使用语义化 section 和稳定的 CSS Grid/Flex 布局；不要依赖浏览器默认 margin。
- 为经历块设置 `break-inside: avoid`，但不要因此造成大块空白；必要时允许要点在合理边界断开。
- 不加入联网、上传数据或执行第三方代码的脚本。脚本只允许实现本地照片选择与预览、打印、文字编辑、排版工具栏、恢复默认值、可选的本地文件保存以及溢出检查；打印时所有工具按钮与交互提示隐藏。
- 屏幕缩放不改变打印尺寸。

## 验收检查

在交付前必须完成浏览器或可靠本地渲染器的屏幕态与 A4 打印态检查；仅检查源代码中是否出现 A4 CSS 不算验收完成。若当前环境无法完成渲染检查，应明确说明限制，不能声称已经通过视觉验收：

- 页面实际为 210mm × 297mm，打印边距为零且无浏览器自动页眉页脚（提醒用户在打印对话框中关闭页眉页脚）。
- 内容只有一页；无横向溢出、遮挡、裁切、孤立标题或不可读小字；内容高度与 A4 可用区域协调，页底没有不合理的大面积空白。
- 姓名、组织、岗位、日期和模块线条对齐。
- 所有文字可直接编辑，编辑提示和打印按钮不出现在 PDF 中。
- 正文大小、行间距、段间距控件可用且受安全范围约束；选中文字后可加粗、设为斜体，并且打印结果保留这些格式。
- 调整排版参数后溢出状态会即时更新；恢复默认值能够回到交付时已经验收的版面参数。
- 点击照片占位框能够选择本地图片；选择后图片正确显示并按证件照区域裁切，替换照片不会改变页面布局；整个过程无网络请求。
- 无网络请求；断网打开后布局和图标完整。
- HTML 中未残留用户未确认的示例文字、占位示例或开发注释。

交付 HTML 文件，并简要说明：HTML 已逐字采用确认版 Markdown；用浏览器打开后可以查看并提出修改建议，也可直接点击文字修改；打印时选择 A4、缩放 100%、边距无、关闭页眉页脚并另存为 PDF。
